Protección de datos

Política de privacidad

Este es un proyecto conceptual no oficial administrado por Michael Studio Web. Bedda Madre no controla esta página ni recibe sus datos analíticos.

1. Responsable

El responsable de esta demostración es el autor que utiliza la denominación creativa Michael Studio Web. Las solicitudes relacionadas con privacidad pueden enviarse mediante los canales de contacto publicados en su portafolio.

2. Datos tratados

El sitio no contiene formularios, cuentas de usuario ni pagos. Al acceder, el proveedor de alojamiento puede tratar datos técnicos, como la dirección IP, fecha y hora, navegador o información necesaria para seguridad y entrega del contenido.

Si el visitante acepta voluntariamente las cookies analíticas, Google Analytics podrá generar estadísticas sobre páginas vistas, dispositivo, navegador, procedencia aproximada y uso general del sitio. No se solicita nombre, correo, teléfono ni datos de pago.

3. Finalidades y bases jurídicas

  • Alojamiento y seguridad: permitir la publicación, proteger el servicio y diagnosticar incidencias.
  • Analítica opcional: conocer de forma agregada cómo se utiliza la demostración. Su base jurídica es el consentimiento, que puede retirarse en cualquier momento desde “Configurar cookies”.

4. Proveedores

  • GitHub Pages / GitHub, Inc.: alojamiento del sitio y registros técnicos de seguridad.
  • Google Analytics / Google Ireland Limited: analítica opcional, únicamente después de aceptar cookies y cuando la integración sea activada.
  • Google Fonts / Google Ireland Limited: entrega de las tipografías utilizadas por la interfaz; la solicitud técnica puede incluir la dirección IP y datos del navegador.

Estos proveedores pueden realizar tratamientos internacionales conforme a sus condiciones, garantías y políticas de privacidad.

5. Conservación

La elección de cookies se conserva localmente durante un máximo de doce meses. Cuando se active Google Analytics, el responsable deberá configurar una retención limitada y revisar periódicamente que no se recopilen datos innecesarios.

6. Derechos

Las personas pueden solicitar acceso, rectificación, supresión, oposición, limitación o portabilidad cuando proceda. También pueden retirar el consentimiento de analítica desde el enlace “Configurar cookies” y presentar una reclamación ante la Agencia Española de Protección de Datos.

7. Enlaces externos

Al seguir enlaces hacia Google, Instagram, Glovo, Just Eat, mapas u otros servicios, se aplican las políticas de esos terceros. Michael Studio Web no controla los tratamientos realizados una vez abandonado este sitio.

8. Cambios

Esta política deberá revisarse si se añaden formularios, reservas internas, pagos, publicidad, nuevas herramientas de medición o si el proyecto pasa a ser una web oficial.
